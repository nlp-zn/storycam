# Plans

Execution plans are first-class repo artifacts.

## Locations

- Active plans: `exec-plans/active/`
- Completed plans: `exec-plans/completed/`
- Tech debt: `exec-plans/tech-debt-tracker.md`

## Rules

- Do not implement large work without an active plan.
- Each task needs acceptance criteria and verification.
- Prefer vertical slices that leave the system working.
- Move completed plans to `completed/` with a completion note.
- If product scope changes, update product specs and active plans together.
