# StoryCam Design Core Beliefs

## 1. Ordinary Users First

Users should not need to understand prompts, shot tables, model parameters, or production pipelines. The UI should translate professional directing concepts into plain choices and visible story artifacts.

## 2. Story Before Video

The product should help users feel the story, people, and place taking shape before any video call begins. Do not skip script, character assets, and scene assets.

## 3. Core Groups Are Clips

Each core storyboard group is a video clip group. Expanded storyboard cards are guidance inside that group unless a future product spec says otherwise.

## 4. Private By Default

The product handles private memories, relationships, fantasies, and photos. Trust language should appear before external generation boundaries, not only in settings.

## 5. Cinematic But Lightweight

StoryCam should feel warm, cinematic, and personal. Avoid cyber workstation, industrial dashboard, or creator marketplace language in the first version.
