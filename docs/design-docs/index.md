# Design Docs Index

Design docs define how StoryCam should feel and how UI should behave.

## Canonical Design Docs

- `core-beliefs.md` — StoryCam design beliefs for agent and human contributors.
- `storycam-ui-design.md` — first Web prototype UI brief.
- `assets/storycam-ui-flow-board.png` — generated UI flow board.
- `stitch_storycam_cinematic_workstation/` — Stitch reference snapshots. Use as structural reference, not as final product tone.

## Design Rules

- Build the actual creative workflow, not a marketing landing page.
- StoryCam should feel like a private mini-theater camera, not an industrial short-drama backend.
- Keep professional directing methods internal; expose lightweight user choices.
- Make the story-world confirmation stage visible and emotionally legible.
- Show core storyboard groups as clip groups, not decorative still images.
