# Design

StoryCam's first UI should feel like a private mini-theater camera.

## Principles

- Build the actual guided creation flow, not a landing page.
- Keep the first version Web-first.
- Show story world confirmation before storyboard or video generation.
- Treat core storyboard groups as video clip groups.
- Use ordinary language: `我的剧本`, `人物`, `地点`, `这一段会这样拍`, `生成最终作品`.
- Do not expose `prompt packet`, `Shanyin-style shot data`, model parameters, or professional shot tables.
